# Smart City WiFi Security

This project detects suspicious and malicious WiFi network behavior in a smart city environment using classification-based machine learning models.

## Problem Statement
With the increase in public WiFi usage, detecting insecure or malicious network activity is critical for smart city infrastructure.

## Approach
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Classification modeling

## Models Used
- Logistic Regression
- Naive Bayes
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Tools Used
- Python
- Pandas, NumPy
- Scikit-learn

## Key Learnings
- Handling classification problems
- Model comparison and evaluation
- Security-focused ML use cases
